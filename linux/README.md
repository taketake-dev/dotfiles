# Linux設定

Linux（WSL2 / Ubuntu）で使うBash・Git・nano・Vimの設定を管理します。

## 管理するもの

- `.bash_aliases`: `ta` でtmuxの既存セッションに接続し、なければ開始するエイリアス。
- `.gitconfig`: Gitのユーザー名・メールアドレス、新規リポジトリのブランチ名、認証情報のキャッシュ設定。導入前に自分のユーザー情報を確認してください。
- `.nanorc`: nanoで行番号を表示する設定。
- `.vimrc`: Vimの設定用ファイル。現在はコメントのみです。
- `install.sh`: 上記4ファイルの導入処理。

設定はこのディレクトリ内の原本を編集します。

## 導入

リポジトリのルートで実行します。

```bash
bash linux/install.sh
source ~/.bashrc
```

4つの設定ファイルをホームディレクトリの同名パスへシンボリックリンクで配置します。`source ~/.bashrc` はBashの設定を読み直す操作です。Codexの設定は配置しません。

## 既存の設定がある場合

全対象を事前検査し、同じ原本を参照するリンクは何もしません。別のファイル・フォルダ・リンクがあれば、その場所を表示してリンク作成前に停止します。既存の設定は上書き・削除・移動しません。親ディレクトリがファイルなどになっている場合も停止します。

実行時の権限やI/Oエラーで途中終了した場合、自動ロールバックはしません。完了したリンクは表示され、再実行時には同じ原本へのリンクとして扱います。

## 一時ディレクトリでの検証

存在する一時ホームの絶対パスを指定すると、実際の個人設定を変更せずに検証できます。リポジトリのルートで実行します。

```bash
bash linux/install.sh /absolute/path/to/test-home
```

`install.sh` はLF改行で保存してください。

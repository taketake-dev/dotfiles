# Codex設定

個人用Codexの指示と自作スキルの原本を管理します。

## 管理するもの

- `AGENTS.md`: 個人用Codexの指示。現在はWindowsで使うツールの説明も含むため、別の環境では内容を確認してください。
- `.agents/skills/`: 自作スキル。`implementation-plan` は `$implementation-plan` の明示指定時だけ使用します。
- `install.ps1`: Windows用の導入処理。PowerShell 7で実行します。
- `install.sh`: Linux用の導入処理。

設定・スキルはこのディレクトリ内の原本を編集します。付属スキルやプラグイン、個人用Codexフォルダ全体は置き換えません。

## Windowsでの導入

リポジトリのルートで実行します。

```powershell
pwsh -File .\codex\install.ps1
```

`AGENTS.md` は `$HOME\.codex\AGENTS.md` へファイルのシンボリックリンク、`.agents/` 全体は `$HOME\.agents` へジャンクションで配置します。

ファイルのシンボリックリンクを作るには、Windowsの開発者モードまたは管理者権限が必要な場合があります。作成できなければエラーで終了し、設定や権限は自動変更しません。

## Linuxでの導入

リポジトリのルートで実行します。

```bash
bash codex/install.sh
```

`AGENTS.md` は `~/.codex/AGENTS.md` へ、`.agents/` 全体は `~/.agents` へシンボリックリンクで配置します。BashなどのLinux設定は配置しません。

`.agents/` 配下にアプリなどが作成するファイルも、このリポジトリの `codex/.agents/` に保存されます。Gitへの追加は内容を確認して行ってください。

## スキルの追加・更新

`.agents/skills/<スキル名>/SKILL.md` を追加します。`.agents/` 全体をリンクするため、新しいスキルの追加時も導入スクリプトの再実行は不要です。導入時には `.agents/skills/` 直下のスキルディレクトリを検査し、`SKILL.md` がない場合は停止します。

既存スキルの内容を編集した場合、リンク経由で反映されるため、導入スクリプトの再実行は不要です。Codexで認識されない場合は、Codexを再起動して確認してください。

## 既存の設定がある場合

`.agents` と `AGENTS.md` の全対象を事前検査してから、配置します。

- 正しい原本を参照するリンク: 何もせずスキップします。
- 別の場所へのリンク・切れたリンク: リンクだけを張り替えます。元のリンク先の中身は変更しません。
- 実ファイル・実ディレクトリ: 空ディレクトリも含め、何も変更せず停止します。

Windowsではシンボリックリンクとジャンクションをリンクとして扱います。親ディレクトリがファイルや切れたリンクなどで使えない場合も停止します。

個人用AGENTSをこのリポジトリへコピーしただけでは導入は完了しません。配置先のAGENTS.mdが通常ファイルなら導入処理は停止するので、内容を確認してから配置を切り替えてください。

実行時の権限やI/Oエラーで途中終了した場合、自動ロールバックはしません。完了したリンクは表示され、再実行時には正しい原本へのリンクとしてスキップします。リンクの張り替え中に失敗した場合、元のリンクが外れた状態で残ることがあります。

## 一時ディレクトリでの検証

存在する一時ホームの絶対パスを指定すると、実際の個人設定を変更せずに検証できます。リポジトリのルートで実行します。

```powershell
pwsh -File .\codex\install.ps1 -HomeDirectory C:\path\to\test-home
```

```bash
bash codex/install.sh /absolute/path/to/test-home
```

`install.sh` はLF改行で保存してください。

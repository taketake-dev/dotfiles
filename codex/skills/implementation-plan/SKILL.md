# 実装前の計画の提示

ユーザーが `$implementation-plan` を明示的に呼び出したときだけ使用する。自然言語による相談、作業開始、変更規模を理由に自動実行しない。

## 対象と範囲

- 現在の依頼と会話から、計画する変更と対象プロジェクト・環境を確認する。指定された場所と、現在の作業ディレクトリや別のチェックアウトを混同しない。
- 計画を日本語でチャットに表示する。ユーザーのタイポは直し、コード・コマンド・固有名詞は正確に記載する。
- このスキルでは、ファイルの作成・更新・移動・削除、インストール、設定変更、Gitへの書き込み、スケジュール登録、実装を行わない。計画の提示や採用を、それらの実行許可とみなさない。
- 調査は読み取りに限定する。状態を変更する起動・ビルド・テストなどを、現状確認のために実行しない。別途許可された検証の結果は根拠として使用できる。

## 手順

1. 最新のユーザー指示、適用されるルール、確定要件、既存の構成・関連コード・設定を必要な範囲で読む。読み取り権限のない場所にはアクセスせず、調査範囲や資料の指定を守る。
2. 計画に影響する未決定事項を洗い出す。保存先、対象範囲、外部サービス、運用方法など、先に決めないと計画が大きく変わる点は、おすすめと理由を添えて質問する。会話で決まった事項を再質問しない。
3. 現状と確定要件に沿って、最もシンプルな構成を考える。必要な機能・API・実行条件が利用できるか、公式資料などで確認する。未確認の動作を保証しない。
4. 下記の項目から対象に必要な内容を提示する。大きな変更では構成図と変更一覧を具体的にし、小さな変更では簡潔にする。依頼されていない機能や管理用ファイルを、項目を埋めるためだけに増やさない。
5. 構成図・変更一覧・処理の流れ・実装順を照合し、漏れや矛盾を直す。未確定事項と未検証の動作を明記し、計画の提示で終了する。

## 提示する内容

### 目的・現状・対象範囲

- 実現すること、確認できた現在の構成、今回の変更対象を説明する。
- 確認済みの事実、ユーザーが確定した要件、提案、未確認事項を区別する。未承認の提案を要件として扱わない。

### 完成予想のディレクトリ構成

- 対象のルートを明記し、作成・変更するディレクトリと主要ファイルをツリーで表示する。各項目に役割を添え、既存・新規・変更予定の区別が分かるようにする。
- 各階層はディレクトリを先、ファイルを後にし、それぞれ名前順に並べる。既存の配置ルールとユーザーの指定を優先する。
- 「全部」の指定がある場合は、予定するディレクトリを漏れなく示す。繰り返し作る場所は `<対象ID>` などで表し、その意味を説明する。自動生成される内部構造を省略する場合は、その範囲を明記する。
- 未決定のファイル名・モジュール分割は仮案と示す。クラス名やメソッド名まで根拠なく確定せず、不要な空ディレクトリも計画しない。

### 変更予定一覧

- 場所・対象、操作の種類、新規または変更後の内容、必要な理由・影響を整理する。比較しやすい場合は表を使う。
- ファイル以外の変更も含める。関係する場合は、依存関係、PCの設定、権限、環境変数、起動時処理、定期実行、外部サービス、Git管理・除外対象を明示する。
- 絶対パスを確認できる対象は正確に示す。将来作る場所や例示の値を、存在確認済みと表現しない。秘密情報は載せない。

### 処理の流れ・運用

- 誰が、いつ、何を入力として受け取り、どこへ読み書きし、何を出力するかを説明する。
- 自動実行がある場合は、実行主体、起動条件、手動実行、停止方法、未実行・失敗・重複実行の扱いを示す。モデルへの送信範囲や利用量が関係する場合は、それも説明する。

### 実装順・検証・復旧

- 依存関係に沿った作業順と、何を確認できれば完了かを示す。実施予定の検証と、すでに実施した検証を区別する。
- 既存データや設定に影響する変更では、必要なバックアップ・復旧方法を示す。復旧できない操作は、その旨を明記する。

### 未決定事項

- ユーザーが決める必要のあること、選択肢、おすすめと理由をまとめる。現在の環境で未確認の点には、確認方法を添える。
- 重大な未決定事項が残る場合は暫定案と示す。質問への無回答を承認として扱わない。

## 最後の確認

- 構成図にある作成・変更対象が変更一覧から抜けておらず、変更一覧の対象が構成図や説明で追えること。
- 処理に必要な設定・保存先・実行主体がそろい、予定の権限と読み書きの範囲が一致していること。
- 既存の仕様を未確認の機能で置き換えていないこと。利用量・時間などの見積もりは根拠と不確実性を添えること。
- 小さな変更に不要な仕組みを追加しておらず、計画を書くためのファイル変更を行っていないこと。
